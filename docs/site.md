# Сайт документации

Руководства хранятся в обычных Markdown-файлах каталога `docs/`. Сайт собирает из них страницы с боковой навигацией, поиском и подсветкой команд. Отдельно поддерживать копии текста для GitHub и сайта не нужно.

## Запустить локально

Нужен Node.js 24. Из корня репозитория:

```bash
npm ci --prefix docs
npm run dev --prefix docs
```

Откройте [http://localhost:5174](http://localhost:5174). Изменения Markdown и оформления видны сразу. Веб-интерфейс фермы на порту 5173 работает независимо.

## Проверить перед публикацией

```bash
npm run build --prefix docs
npm audit --prefix docs --audit-level=high
npm run preview --prefix docs
```

Сборка находится в `docs/.vitepress/dist/`. Предпросмотр открывается на [http://localhost:4174](http://localhost:4174). Для публикации нужен обычный сервер статических файлов; подключения к API фермы и секреты не требуются. Этот каталог можно перенести целиком. Используются страницы `.html`, поэтому специальный fallback для маршрутов не нужен.

## Изменить структуру

- Текст страницы — соответствующий `.md` внутри `docs/`.
- Порядок разделов слева — `sidebar` в `.vitepress/config.mjs`.
- Цвета и размеры — `.vitepress/theme/style.css`.
- Логотип — `public/logo.svg`.

Файлы `README.md` остаются удобными для чтения в GitHub; на сайте они становятся главными страницами своих разделов. CLI и примеры интеграций можно скачать прямо с сайта; сборка копирует только явно перечисленные публичные файлы из `.vitepress/downloads.mjs`. Зависимости, настройки окружения и секреты туда не попадают. Ссылки на остальные исходники открывают репозиторий. OpenAPI копируется в готовую сборку и доступен по ссылке из API-руководства.

VitePress закреплён в `package-lock.json`. Для него используется исправленная ветка Vite 6 через `overrides`: стандартная зависимость VitePress 1.6.4 содержит известные уязвимости Vite 5. При обновлении версий повторите сборку и аудит.
