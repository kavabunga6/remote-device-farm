# Полный сброс физических устройств

Для многопользовательской аренды нужны **полный сброс и повторная подготовка**.
Частичная очистка приложений и файлов через ADB не гарантирует удаления аккаунтов,
куки, ключей, системных данных и настроек предыдущего пользователя.

## Настройка

```dotenv
AGENT_USB_ENABLED=1
AGENT_USB_ALLOWLIST=YOUR_DEVICE_SERIAL
AGENT_USB_WIPE=command
AGENT_USB_WIPE_CMD=/opt/device-tools/reprovision-android
```

Команду создаёт администратор для конкретной модели: например, доверенное
восстановление golden-образа через fastboot/recovery или полный сброс средствами
Android Enterprise/MDM с повторным provisioning. Монтируйте её и прошивку read-only;
агент и арендаторы не должны иметь возможности изменить эти файлы. Агент вызывает
`script <serial>` без shell; не указывайте аргументы в переменной пути.

Без allowlist, режима `command` и явного пути агент не включит USB-провайдер.
**Встроенный `reset-android.sh` больше не принимается:** это старый инструмент
частичного восстановления для ручного обслуживания, не очистка перед выдачей.

## Контракт скрипта

- Стирает приватные данные всех пользователей и приложений, аккаунты и общий
  накопитель, восстанавливает доверенную прошивку/конфигурацию по вашей политике.
- Выполняет полный reset и provisioning; один reboot не является очисткой.
- Восстанавливает ADB-доступ агента и завершает мастер настройки.
- Идемпотентен, возвращает ненулевой код при любом сомнении; общий таймаут — 20 минут.
- Возвращает `0` только после готовности устройства к независимой проверке агента.

После команды агент проверяет новый `boot_id`, завершённую настройку, отсутствие
канареек, пользовательских приложений и лишних файлов. Канарейки выявляют часть
ошибок сброса; их удаление **не доказывает криптографическое стирание**. Полноту
сброса подтверждает проверенный процесс восстановления для вашей модели.
При любой ошибке телефон остаётся в карантине и следующему пользователю не выдаётся.

## Приёмка на железе

На отдельном тестовом телефоне оставьте данные в приложениях, браузере, аккаунтах,
общем накопителе и настройках. Завершите сессию и проверьте следующую аренду;
повторите с обрывом USB, перезапуском агента и ошибкой скрипта. Во всех неуспешных
случаях устройство должно оставаться недоступным. Учитывайте ограничения производителя,
защиту загрузчика, FRP и возможности MDM. Не тестируйте wipe на личном телефоне.

В репозитории проверены модель телефона, канарейки, карантин и конкурентная выдача.
Полный сброс настоящего физического устройства пока не сертифицирован.
