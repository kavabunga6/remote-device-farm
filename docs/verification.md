# Проверки и ограничения

Remote Device Farm находится в состоянии **alpha**. Проверка одной конфигурации не подтверждает совместимость с другим устройством, образом или окружением.

## Проверенные сценарии

| Сценарий | Область проверки |
| --- | --- |
| Установка на одном Linux-хосте | Пустая БД, отдельные тома, подключение сервера и агента |
| Резервное копирование и восстановление | PostgreSQL, `app_store`, `registry_data` и расшифровка сохранённых настроек; синтетические APK и образ registry |
| Google APIs / API 36.1, x86_64 | Загрузка телефона и планшета, ресурсы Android, SELinux, подключение доверенного ADB-ключа и отказ независимому клиенту |
| NVIDIA | Запуск телефона; другие GPU требуют отдельной проверки |
| HTTPS и registry | Конфигурация nginx и авторизация API управления образами |
| Интерфейс для ПК | Русский и английский языки, светлая и тёмная темы, увеличенный текст |
| Доступ к сессиям | Изоляция двух аккаунтов, просмотр и управление по общей ссылке, отзыв и истечение срока |
| Команды, очередь и аренда | Разрешённые профили, лимиты участников, назначение из очереди, продление и истечение аренды |
| REST API и UI | Проверка маршрутов, схем и прав OpenAPI; браузер с настоящими HTTP-маршрутами, авторизацией и временной PGlite, с моделью RPC агента |
| CI-пакеты | GitLab-скрипт с CLI и моделью API; Groovy-тесты Jenkins; Gradle TestKit 8.14.5 и 9.3.1, вложенная сборка, configuration cache и установка Maven-пакета |
| Ограниченный сборщик | Небольшой образ: выполнение `RUN`, экспорт, потоковый импорт, запуск результата и удаление созданных ресурсов |

Восстановление проверено между отдельными томами одного физического хоста. Хранение APK не подтверждает установку этого APK в Android. Проверка небольшого образа не подтверждает полную сборку Android SDK.

## Not tested

| Сценарий | Требуемая проверка |
| --- | --- |
| Скачивание образа независимым узлом | Второй Linux/KVM-хост или VM с собственным Docker и пустым кэшем; скачивание и запуск по digest |
| Полная сборка SDK с ограничением ресурсов | Выделенный сборщик: сборка, проверка Android, загрузка в registry, отмена и очистка |
| Android TV, Automotive и Wear | Загрузка соответствующих SDK-образов, экран, управление, ADB и очистка |
| DRI на Intel/AMD | Фактический рендерер и жизненный цикл на поддерживаемых GPU и драйверах |
| Устаревшие адаптеры образов | Совместимость каждого базового образа с текущим агентом до включения профиля |
| Повторная выдача физического устройства | Полный сброс каждой поддерживаемой модели; отсутствие данных предыдущего аккаунта |
| ADB физических устройств | Доступ двух независимых аккаунтов и отзыв доступа при завершении аренды |
| Keycloak/OIDC и LDAP/LDAPS | Реальные провайдеры: вход, выход, сопоставление учётных записей, права и отказ провайдера |
| Внешние webhook-получатели | Доставка, подписи, повторы и обработка ошибок реального получателя |
| Восстановление ввода и качество звука | Обрывы во время жестов, поворот экрана, воспроизведение и синхронизация звука |
| Освобождение по бездействию с подключённым ADB | Применение политики, освобождение слота и удаление контейнера |
| Длительная многопользовательская нагрузка | Очереди, Logcat и управление сессиями с контролем CPU, памяти и диска |
| WAN и TURN | Подключение вне локальной сети, задержки, потери и ограниченная полоса |
| Изоляция хоста и локальной сети | Правила firewall и контролируемые сетевые цели в отдельном окружении |
| Отказы Docker и перезагрузка хоста | Сохранение владельцев, состояния очистки и обнаружение оставшихся ресурсов |
| GitLab, Jenkins и Android Gradle Plugin | Запуск в реальных CI-системах, отмена, JUnit и instrumentation с AGP/SDK; [руководства по интеграциям](ci/README.md) |

Аренда физических устройств должна оставаться выключенной до успешной проверки полного сброса и подготовки каждой модели. Изоляция сети и нагрузочные пределы проверяются для конкретной установки до предоставления доступа недоверенным пользователям.

## Ограничения

- Поддерживается один экземпляр сервера.
- Снимки загрузки Android и привилегированные контейнеры эмуляторов недоступны.
- Автоматическая адаптация битрейта к полосе сети не реализована.
- Роли приложения не синхронизируются с группами внешнего каталога.
- Очередь физических устройств и фильтры по модели/ОС в диалоге аренды не реализованы.
- CLI использует ресурсы профиля; отдельные CPU/RAM-переопределения для сессии недоступны.
- Стартовые профили без подтверждённой совместимости остаются выключенными.

## Автоматические проверки

Тесты проверяют серверные API, права доступа, миграции, жизненный цикл агента, ограничение ресурсов, транспорт ADB и интерфейс. Наборы с mock API и моделью Android-протокола не подтверждают загрузку Android, аппаратный рендеринг или очистку физического устройства.

Команды находятся в [руководстве по разработке](development.md). При установке используйте [чек-лист проверки](release-checklist.md) и [требования безопасности](../SECURITY.md).
