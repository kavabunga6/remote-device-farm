# Сервер Remote Device Farm

Сервер отвечает за вход пользователей, API, распределение слотов и историю. Состояние хранится в PostgreSQL; агенты подключаются к серверу по WebSocket.

- [Установить и обновить сервер](../docs/deployment/server.md).
- [Запустить код локально](../docs/development.md).
- [Примеры API](../docs/api/README.md).
- [Технический справочник API и протокола](../docs/reference/server.md).
- [Готовые и собственные образы устройств](../docs/emulator-images.md).

Основной код находится в `src`, маршруты — в `src/routes`, миграции — в `migrations`. Миграции применяются при старте сервера.
