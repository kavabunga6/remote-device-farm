# Веб-интерфейс Remote Device Farm

Интерфейс написан на React и TypeScript. В контейнере nginx раздаёт статику и передаёт запросы API серверу. Браузер не подключается к агенту напрямую.

## Работа над интерфейсом

```sh
npm ci
npm run dev:live -- https://farm.example.com
```

Откройте http://localhost:5173 и войдите учётной записью подключённой фермы. Изменения файлов появятся сразу. Адрес в команде замените своим.

[Полная инструкция по разработке](../docs/development.md) описывает демонстрационный режим, другой порт и проверки перед отправкой изменений.

## Основные файлы

- `src/api.ts` — запросы к серверу и типы данных.
- `src/SessionView.tsx` — рабочее место с устройством.
- `src/useSessionStream.ts` — поток экрана и звука.
- `dev/run-live.mjs` — запуск Vite с реальным API.
- `dev/run-mock.mjs` — запуск с демонстрационными данными.

Для декодирования видео через WebCodecs нужен HTTPS или localhost. [Настройка HTTPS](../docs/deployment/server.md) входит в руководство установки.
